# Evidence-Locked Major Comment Template

**MAJOR COMMENT [MC-#] — [short title]**

**Priority:** P0 / P1 / P2  
**Claim ID(s):** C-#  
**Evidence anchor(s):** [MS]/[SUPP]/[CODE]/[DATA]/[CALC]/[CROSS]/[EXT]/[INF]/[EXT-REQ]/[UNK] + exact location/source  
**Reviewer confidence:** High / Moderate / Low  
**Steelman survival:** Yes / No

**Issue**  
Precisely state the problem.

**Mechanism of concern**  
Explain why the cited evidence does not support the affected claim as written.

**Scientific consequence**  
State what interpretation, estimate, mechanism, prediction, novelty claim, validation claim, or generalization changes.

**Alternative explanation (if relevant)**  
State the strongest serious alternative, not a speculative list.

**Minimum resolution**  
State the smallest sufficient change: clarification, correction, reanalysis, additional evidence, or claim narrowing.

**Optional stronger resolution**  
Include only if genuinely useful and explicitly nonessential.

**Closure criterion**  
Define the observable condition that would count as resolved, including the outcome that would require weakening the claim.
