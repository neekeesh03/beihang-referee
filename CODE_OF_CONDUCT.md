# Community Code of Conduct

Beihang Referee is a technical and scientific open-source project. Participation should make it easier for people to examine evidence, reproduce behavior, disagree constructively, and improve the software.

## Expected conduct

Contributors and users should:

- discuss code and scientific claims on their merits;
- distinguish evidence from speculation and state uncertainty when relevant;
- give actionable, reproducible feedback where possible;
- respect different levels of experience and different disciplinary backgrounds;
- avoid sharing confidential manuscripts, credentials, private data, or other material you are not authorized to disclose;
- accept that maintainers may reject changes that weaken provenance, security, reproducibility, or scientific safeguards.

## Unacceptable conduct

Harassment, threats, discriminatory abuse, deliberate exposure of private information, credential leakage, malicious code, knowingly fabricated evidence, and repeated bad-faith disruption are not acceptable.

Scientific disagreement is welcome. Personal attacks are not.

## Enforcement

Maintainers may edit or remove inappropriate issue/PR content, close discussions, reject contributions, or restrict participation when necessary to protect contributors, users, repository integrity, or confidential information.

For a sensitive conduct or security matter, use a private repository reporting channel when one is available rather than posting details publicly.
