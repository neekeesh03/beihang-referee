# Benchmarking guide

The synthetic corpus contains more than four hundred fictional manuscripts with planted defects spanning causal identification, data leakage, validation optimism, denominator inconsistencies, confidence-interval contradictions, multiplicity, obsolete baselines, novelty overclaiming, unit errors, pseudoreplication, preregistration drift, missing controls, overgeneralization, reporting gaps, figure/text conflicts, prompt injection, unresolved citations, and scientifically sound negative controls.

Separate revision-pair and rebuttal corpora test whether the system distinguishes actual scientific closure from cosmetic rewriting. All corpus records are explicitly marked synthetic and contain no authoritative scientific evidence.

Use deterministic structural benchmarks for admission-gate regression. Use model-backed benchmarks for reviewer recall, false-positive rate, closure accuracy, disagreement stability, and source-grounding precision.
