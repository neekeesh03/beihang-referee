# Revision and rebuttal auditing

Textual change is not scientific resolution. Revision workflows should begin with a stable registry of prior concerns and their closure criteria, compute a structural manuscript diff, locate the affected sections, and then independently reassess whether the scientific failure mechanism has been removed.

Rebuttal auditing separately evaluates traceability. A response should map reviewer comment → author response → manuscript location → changed evidence. Statements such as “addressed as requested” without a verifiable location or substantive change are not treated as closure.
