# Quality gates

Global scores do not override failed scientific gates. Recommended gates include claim support, design-identification adequacy, statistical validity, validation integrity, data leakage, numerical consistency, ethics/integrity, reproducibility sufficiency, and literature/novelty grounding. Gate outcomes should be reported individually with uncertainty.

A manuscript can be beautifully written and still fail a central scientific gate; conversely, presentation weaknesses should not be inflated into major scientific objections.
